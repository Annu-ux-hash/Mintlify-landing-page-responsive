# Mintlify Website Clone

A frontend recreation of the Mintlify website built using **HTML and Vanilla CSS**.

## 🎯 What I Learned

This project helped me understand CSS more deeply by building a real-world website layout from scratch.

- Learned new CSS properties and discovered better ways to write CSS.
- Practiced building layouts using **Flexbox and CSS Grid**.
- Improved my understanding of positioning, spacing, sizing, and element alignment.
- Learned how to control and target elements more easily using CSS selectors.
- Explored CSS custom properties (`--variables`) for reusable colors, fonts, and other design values.
- Understood how background images, layering, and `z-index` work.
- Improved my ability to recreate layouts by observing design, spacing, typography, and colors.
- Learned to write structured CSS without relying on frameworks or libraries.

## 🛠️ Built With

- HTML5
- Vanilla CSS

## 💡 Key Takeaway

The biggest takeaway from this project was learning that writing CSS is not just about making things look right. It is about understanding how elements behave, choosing the right properties, and finding simpler ways to control layout and styling.

Every challenge helped me discover a new approach and improve my frontend development skills.

## 🚀 Next Steps

Continue improving the design, refining the CSS, and making the website responsive across different screen sizes.
